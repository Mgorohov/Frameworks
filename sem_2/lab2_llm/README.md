## Описание работы
Прототип системы автоматического одобрения кредитов с использованием LLM.  
Сервис принимает характеристики клиента и возвращает вердикт с объяснением, используя инструменты расчёта кредитного скора и оценки риска.

## Архитектура
- **ollama** — Docker-контейнер с моделью `qwen2.5:0.5b`
- **mcp_service** — FastAPI + FastMCP сервер с двумя инструментами:
  - `calculate_credit_score`
  - `calculate_risk`
- **Клиент** отправляет запросы к сервису (порт 8000)

## ML-часть
Обучена модель `RandomForestClassifier` на **Adult dataset** (UCI).  
Метрики на тестовой выборке: Accuracy 0.86, Precision 0.75, Recall 0.62, F1 0.68.  
Модель подключается автоматически при совместимости версий библиотек.
